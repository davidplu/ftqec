# Population diversity

Exact physical identities exclude cosmetic record labels and include physical operations, qubits, schedules, detectors, observables, and boundaries. Architecture descriptors separately record family, stabilizer basis, interaction order, rounds, flag style, verification, allocation, and scheduling choices. Resource vectors and detector counts complement these descriptors.

Coarse descriptor buckets are labelled near-duplicate classes, not proven fault equivalence classes. Distinct circuit hashes alone do not establish meaningful diversity. Final scientific reporting must show distributions across independent architecture dimensions, physical structure, resources, and measured fault information where available.

Selection reserves representation for each generated architecture family, combines resource elites with deterministic exploration, and retains certified alternatives. All candidate ancestry is generated from code-only inputs; preserved reference/control circuits are used only in separately labelled comparisons or verification studies.

Candidate goals count canonical timed physical structures: disjoint simultaneous operation order and detector-list order cannot inflate this count. Original exact identities remain preserved for certificate binding. This normalization does not merge arbitrary code equivalences or approximate physical faults.
