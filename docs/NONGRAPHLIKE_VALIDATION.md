# Non-graphlike validation

The development study produced target-five positive certificates using the complete raw-signature MITM method. The tested CSS circuit has physical alternatives affecting more than two raw detectors. Its raw hyperedges were not decomposed or replaced for MITM. Independent forward-inventory reconstruction, recursive partition enumeration and reverse joins verified the exclusion.

This surface-family example also admits useful graph projections. Thus it demonstrates exact certification of genuine raw non-graphlike physical effects, but does not establish efficient certification of projection-ineligible families. The final study records raw hyperedge counts and matched method outcomes. Source-bound raw artifacts, including an interrupted slow database attempt, are retained under results/general_competitive. Consult RESULTS.md for final measured outcomes rather than interpreting this development description as held-out validation.

Small exhaustive physical-alternative oracles test arbitrary signatures, correlated effects, duplicate effects and location exclusivity. SAT tests fix every physical selection on small examples and compare auxiliary satisfiability with the direct fault constraints. These tests support encoding correctness; they do not substitute for an actual target-five circuit certificate.
