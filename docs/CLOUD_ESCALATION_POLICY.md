# Local-first cloud escalation policy

No cloud provisioning or paid resource launch is implemented by this study. First measure local CPU, RAM, disk, proof progress and structural eligibility. Unsupported algorithms and exponential frontier growth do not by themselves justify cloud deployment.

Escalation requires a measured resource deficit for an otherwise justified proof decomposition, a reproducible task plan, spending limits and explicit owner authorization. Retain identical scientific source/model identities, physical semantics, seeds, idempotent retries, checkpoints, monetary accounting and independent replay. Remote execution remains NOT_RUN unless actually demonstrated. Ordinary installation, optimization and small-code certification require no credentials.
