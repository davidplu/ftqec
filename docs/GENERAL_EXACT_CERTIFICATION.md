# General exact certification

The complete operation-local physical fault universe is unchanged: one alternative per physical location, full correlated Pauli alternatives, detector parity and all declared logical effects. Singleton/pair, graph potentials, disk MITM, location DP and bounded SAT are retained. The additional `decomposition` method is exact when its elimination completes and independently verifies.

The automatic portfolio attempts graph certificates where applicable, then component/separator elimination, MITM and the earlier DP as needed. Per-action work, state, CPU and memory safeguards preserve UNKNOWN. None of these methods is claimed to be universally efficient. A solver status alone is not a positive certificate. Ideal code-space boundaries remain distinct from complete physical-memory fault tolerance.
