# Complete circuit export

Run `ftqec export CIRCUIT_ID --run runs/local --format bundle --output exports/finalist` to export one optimizer result. `circuit-json`, `stim` and `schedule-json` are also available. The public ID is the optimizer physical candidate identity, not a filename. The bundle separately records the full serialized circuit identity to which the certificate is bound; independent verification checks both identities. Existing destinations are never overwritten. The bundle includes the input, full compiled circuit, schedule, resources, certificate recipe, source hashes, genome/ancestry fields, selected evaluator task requests/answers, noise, decoder, seeds and reproduction instructions.

`ftqec verify-export exports/finalist --proof-work 20000000` reconstructs and verifies the bundle. `reconstruction_verified`, `certificate_binding_verified`, `proof_replay`, and `positive_certificate_verified` are separate. A historical source mismatch is reported explicitly and never promoted to a new positive proof. Install the matching source to replay old certificates. UNKNOWN receipts can be delivered without claiming certification.

Stim output includes explicitly labeled ideal initial preparation and final stabilizer/logical readout, plus every explicit extraction operation and declared operation-local noise. Its prepared logical-Z-sector experiment is narrower than the arbitrary logical-effect exclusion certificate. Custom record observables are retained. The authoritative full task and source identities accompany standalone Stim output in an identity sidecar. No implicit idle or physical-boundary faults are invented.

Use `ftqec list-results --run runs/local` to obtain the recorded certified-frontier IDs and resources without opening internal directories; `--all` includes failed, UNKNOWN and uncertified candidates. Add `--require-certified` to `verify-export` when a nonzero exit code is required unless fresh positive proof replay succeeds.

A resource-guard termination is an UNKNOWN task outcome, not a completed bound certificate. Direct bundle export rejects such a raw row rather than inventing proof metadata; circuit-json, schedule-json and Stim remain available. The delivered UNKNOWN research record retains the exact outcome in certification_attempt and omits a bound certificate. Use its supplied record path with the same public commands. The final report distinguishes evaluation status from certificate availability.
