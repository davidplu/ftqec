# Adaptive evaluation

The large-population path separates resource/family-based promotion from physical hard rejection. A deferred or statistically uncertain candidate is not INVALID. Physical rejection requires an independently replayed harmful witness, and candidate construction uses the existing exact noiseless checks.

Selected candidates receive an initial simulation batch. The existing confidence-sequence rule spends alpha as alpha/[look(look+1)], allowing repeated inspection across batch looks for each candidate. Uncertain resource-competitive candidates receive a further batch. This per-candidate confidence statement is not automatically simultaneous coverage across the whole search population; final reliability comparisons require a separately frozen multiplicity-aware protocol.

The cost-aware policy retains explicit measured/uncalibrated cost estimates and the direct-certification shortcut. Certified resource frontiers remain separate from estimated resource–LER frontiers. A small number of noisy observations cannot produce a distance certificate or establish universal decoder-independent superiority.

End-to-end population comparisons and fixed-pool evaluation-policy comparisons must remain separate. Actual worker CPU includes process overhead, controller CPU is recorded separately, and summed overlapping worker wall times are never called elapsed session time. Worker overlap alone does not establish parallel speedup.
