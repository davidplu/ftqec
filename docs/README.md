## Reading historical reports

`RESULTS.md`, protocol files, and benchmark specifications belong to particular research epochs. Check their source identities and raw evidence before comparing figures. Later results can supersede an earlier unmet milestone without invalidating the earlier report. A published source snapshot does not include every historical SQLite proof database.
