# Distance-aware synthesis

Every positive integer target is accepted; 1 through 10 is a validation range, not a software maximum. Round counts and cat verification counts have no fixed nine-round ceiling. Per-task resource limits remain explicit. Random generation includes target-dependent repetitions; mutations can increment repetitions and verification depth.

For eligible CSS inputs, greedy hook ordering attempts to preserve the requested lower bound while adding each check's possible propagated data errors. Each search records options examined and the intermediate guiding bounds. Failure to find such an ordering is not code invalidity or proof failure: other architecture operators remain available. No geometric or code-family-specific winning order is embedded.

Construction guidance is deliberately weaker than the scientific acceptance condition. After compilation, all actual correlated two-qubit Pauli alternatives, one-qubit faults and measurement flips enter the complete extraction inventory. An independent forward propagation engine and integer-potential checker validate a positive. No Monte Carlo result is a distance proof.

Operational convergence means an unchanged certified resource-coordinate frontier for the declared number of generations. It is not global optimality or exhaustive neighborhood search. The default is eight unchanged generations; the prospective initial campaign uses three. There is no global wall-time cutoff.
