# Evaluation cost model

The default predictor is a completed-observation median CPU rate scaled by operation count (linear for screening/simulation/target2, quadratic for target3 proof). Censored observations impose scaled lower bounds; they are not completion labels or zeros. Unsupported methods remain a separate category. Cold priors are explicitly uncalibrated and logged. A completed-only log-linear cost fit is evaluated as a comparator, never adopted merely because it fits training data.

Training uses surface-small and Perfect5. Scheduler settings and training observations freeze before Shor/Steane final-family outcomes. Predict cost, never physical validity. Rejection probability is a smoothed empirical screen outcome rate; it is not a certificate.

Task receipts retain scientific-body CPU, sampled whole-process CPU, wall, queue waiting, end RSS and sampled process peak, retries and cache identities. Certification exposes independent-verification cost; Monte Carlo exposes decoder build and inference cost. Compilation, structural checking and resource calculation have separate timing records. Phase RSS snapshots are not phase peaks. The fixed-pool experiment uses serial kernel-body CPU and explicitly reports that execution regime; local process overhead is measured separately, not silently transferred.
