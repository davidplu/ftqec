# Adding an evaluation tier

Scientific evaluation must be independent of its local or remote launcher. Accept a serializable source-bound Task, declare the input circuit/code, noise, decoder, seed and resource limits, and return JSON evidence with CPU/wall scope. Keep hard mathematical rejection separate from statistical deprioritization and UNKNOWN.

Use content-addressed task receipts, atomic publication and checkpoint validation. Preserve errors and work-limit stops. Every positive certificate must receive an independent checker rather than adopting a producer status. Test false rejection with independently verified positive and near-frontier controls before claiming screening savings.

The current conservative scheduler leaves family exploration and uses confidence-aware selection. A new cost model should be prospectively tested against matched compute, not judged only on parallel wall-clock speed.
