# FTQEC publication snapshot

The November 2026 source update includes two-block group-algebra (2BGA) input validation, repeated CSS memory circuits, paired X/Z architecture optimization, BP-OSD decoding, and independently checked physical-mechanism/time-collapse distance certification with affine lifting. The earlier certifiers remain available. See [the public workflow](docs/PHASE3_OPTIMIZATION.md) and [certification contract](docs/TROPIDIST_INTEGRATION.md).

Controlled promotion-policy experiments are ongoing research. Their runners are included, but the incomplete campaign does not establish that one policy outperforms another. See [the interim record](docs/PHASE4_PROGRESS.md). A software release does not mark those experiments complete.

This repository contains source, tests, documentation, and a small redistributable 2BGA example. Large historical proof databases, population databases, archives, and supplied research inputs remain preserved locally. Private correspondence is excluded. Historical experiment scripts and artifact-dependent reproductions require those external data. Report evidence links retain their original layout and may require the local evidence repository. The ordinary software suite uses repository fixtures; passing it does not reproduce every historical scientific result. The earlier baseline's 126-test count describes that historical snapshot, not the current release.

The local project identity remains FTQEC 0.1.0. The original repository and all failed, UNKNOWN and censored experiments remain unchanged by this upload.
