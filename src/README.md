# Source map

`ftqec/cli` implements public commands. `codes` validates stabilizers and derives logical information. `architectures` and `scheduling` construct actual extraction circuits. `circuits` defines their representation and identities. `screening` checks noiseless semantics; `evaluation` accounts resources. `faults` constructs physical effects and independently replays witnesses. `certification` contains graph and general exact methods. `simulation` evaluates decoder-conditional noise outcomes. `optimization` manages candidate populations and durable storage. `execution` supervises bounded workers. `delivery` exports and independently reconstructs circuits and schedules. `results` records artifacts and source identities.

Keep scientific semantics in these shared engines rather than duplicating them in experiment scripts. See [the developer guide](../docs/DEVELOPMENT.md).
