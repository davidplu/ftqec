# Research scripts

These drivers preserve historical experimental protocols, audits and reports. They are not all standalone commands for a fresh clone: some require source-bound archives, proof databases or local paths absent from the publication snapshot. Read each driver and its protocol before execution. Do not point a new experiment at an existing evidence directory.

Use the public `ftqec` CLI for routine optimization, certification and export. Use scripts to reproduce a specific frozen experiment with its exact inputs, source and runtime. Preserve partial results, failed attempts and resource stops. The certification campaign scripts on the experimental branch have a recorded deadline and are not a reusable unrestricted background service.
